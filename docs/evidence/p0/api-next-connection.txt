func (c *Conn) NextConnection(ctx context.Context) (*Conn, error)
    NextConnection transitions a connection to be usable after a 0-RTT
    rejection. It waits for the handshake to complete and then enables the
    connection for normal use. This should be called when the server rejects
    0-RTT and the application receives Err0RTTRejected errors.

    Note that 0-RTT rejection invalidates all data sent in 0-RTT packets. It is
    the application's responsibility to handle this (for example by resending
    the data).
